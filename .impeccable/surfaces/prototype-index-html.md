# Surface brief: app prototype (Today · Live session · Progress)

Scope: clickable design prototype of the app shell and three surfaces, used to pick and record the visual system before the spec. Visitor mode: Operate.
Audience and job: one athlete; know what to do now and at what target (Today), follow it mid-effort at arm's length (Live session), see whether the Program is working (Progress).
Constraints: mobile-first for Today and Live session, desktop-first for Progress, both responsive; system light/dark; WCAG 2.2 AA; funny-blunt Coach copy; sample data labelled as such.
Product name: Compromised (confirmed).

## Direction contract

THESIS: Training run in lanes. Progress is never a ring or a card; it is parallel stripes filling left to right, like the Montréal '76 five-line mark and a track's lanes. Refuses the category default of rounded cards, rings and a single sporty accent.

OWN-WORLD: Cobalt #1B3BB8 field owns the shell (countdown band, primary actions, active nav); white paper, ink #121212, hairline and 2px ink rules instead of cards; five Session-type lane colours (Speed red, Threshold orange, HYROX green, Strength violet, Easy grey). Archivo variable: expanded black striped numerals, condensed heavy headings, regular UI. Square 4px corners, underlined cobalt links, tabular figures everywhere.

STORY: Victor opens the app, reads one number (days to race) and one instruction (the next Session with its exact speed or load), accepts or overrides the Coach's blunt Suggestion, starts the Session, follows lanes filling rep by rep, and later sees the 5K line bending toward 20:00.

FIRST VIEWPORT: Today on a phone: cobalt band with brand and avatar, a 150px striped countdown, five progress lanes with Week and Phase; below on white, the condensed Session heading with target speed and incline, a full-width cobalt Start button with Log after, the Suggestion between 2px ink rules, then this Week's Sessions as lane-chip rows; bottom tab bar with a 2px ink top rule.

FORM: Montréal 1976 Olympic identity program (five-stripe lettering and lane lines); position 1 on the ordered list; seed key af22f41a (chosen as Impeccable's pick).

Signature interaction: lanes fill as work happens: one lane per rep in a Live session, filling with an exponential ease-out against the timer; striped numerals for the countdown and the live target.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
