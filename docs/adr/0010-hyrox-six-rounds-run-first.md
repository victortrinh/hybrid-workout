# HYROX A and B: 6 rounds early, run first

[ADR-0009](0009-hyrox-race-pace-continuous-rounds.md) took Foundation and Build early from 4 rounds to 8, runs at Race run pace, no rest. The athlete did it the next day and found it too much: the rounds were the problem, not the pace or the lack of rest. Four rounds was underloaded and eight overshot, so on 11 November 2026 the dose was set between them, and the round was turned round to match the race.

From Week 1, including the Week under way and a Session already Up next:

- **6 rounds where the Stations are short.** Foundation (Weeks 1–5) and Build early (6–10) do the four Stations, then the last two again: carry and lunges in HYROX A, row and wall balls in HYROX B. Build late and Race specific stay at 4 rounds.
- **Deloads are 3 rounds in every Phase.** Weeks 5 and 10 drop from 6 rounds to 3, as Weeks 15 and 20 already did.
- **Every round is the run, then the Station**, in every Phase, the Deloads and the Taper. The Session ends on a Station (lunges or wall balls), as the race does.
- Everything else in ADR-0009 stands: runs @R at RPE 7–8, rounds straight on, calculated minutes, the Station target counting Sessions.

Why the last two Stations again: the Session still ends on lunges or wall balls, the heaviest Stations (the sleds) come up once, and row, lunges and wall balls are among the Stations that separate finishers most (research note, §1).

Why run first: the race and the Compromised run test are both run then Station. Station then run made every run a Compromised run, but ended the Session on a run and made HYROX A and B the only Sessions in the Program in that order. With the run first, run 1 is fresh and the rest are Compromised runs, so the Fade is read the same way everywhere: a fresh first run against the last.

What it costs: one fewer Compromised run per Session, and the SkiErg, burpee broad jumps and both sleds get one round a Week through Week 10 where ADR-0009 gave them two. Like the dose it replaces, this has no trial behind it.
