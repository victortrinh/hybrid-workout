# HYROX A and B: runs at Race run pace, rounds straight on, 8 rounds early

The plan approved on 7 November 2026 gave HYROX A and HYROX B four rounds of a Station then a run in every Phase, starting from small Station volumes and 400 m runs, billed as 45 minutes. It said nothing about how hard to run or how long to rest between rounds. In Week 1 the athlete did it and found it underloaded: about 12–14 minutes of work behind a 45-minute heading, run at whatever effort felt right, with whatever rest felt right. A Foundation Station is short, so the Session was mostly the warm-up, the Set up and the cooldown.

So from Week 1, including the Week under way and a Session already Up next, every HYROX Session follows one template:

- **Every run is at Race run pace (@R), RPE 7–8.** Week 1 uses the Starting point's estimate until the baseline Compromised run test. Foundation Stations stay "Technique before speed".
- **Rounds run straight on.** No rest is prescribed anywhere, including the join between the two passes through the Stations. The athlete recovers by easing a run. That run is logged as it was run, with no "recovery run" flag, and it counts in the Fade like any other.
- **8 rounds where the Stations are short.** Foundation (Weeks 1–5) and Build early (6–10) go through the four Stations twice with 400 m runs (Build early was 4 × 600 m). Build late (11–15) stays at 4 rounds with runs up to 1 km (was 800 m). Race specific is unchanged. The Deloads in Weeks 5 and 10 do the three-Station rotation twice (6 rounds); Weeks 15 and 20, the Taper and the Race simulations are unchanged.
- **Minutes are an estimate, not a target.** Hand-set per Phase at @R near 5:15/km: about 35 in Foundation, 35 (A) and 40 (B) in Build early, 40 after. The 45-minute Session cap stays a ceiling. Calculating them from the Prescription is a separate change (#178). *Since #178 they are calculated from Race run pace and each Station's estimate; the hand-set table is gone.*
- **The Fade runs from the first run to the last**, run 1 against run 8 in an 8-round Session.
- **The Station target counts Sessions, not rounds.** The Station best can come from any round. The "last two logs at RPE 7 or under" rule that tightens a target needs two Sessions, so two rounds of one Station in a single Session never satisfy it. The Session RPE is the only RPE there is, so counting rounds would let one easy Session count twice.

Why the change: an underloaded Session is a Week of training lost, and an unprescribed run is a run at no particular effort. Doubling the rounds roughly doubles the work in Foundation and Build early without raising any single Station's volume or load, so the Station volume table and its progression stay as they were. Running @R makes every run race-specific work and gives the Fade a fixed pace to fade from.

What has no trial behind it: the volume-then-time progression at fixed Race load had none before (research note, §5) and has none now. This changes the dose inside that model, not the model. Every Session's Training load is still logged so the Program can be judged after Race day.

- **Why not prescribe rest between rounds?** Racing has none. A slowed run is the honest record of what the athlete needed, and a rest clock would hide it.
- **Why not more Station volume instead of more rounds?** Volume is the progression lever the plan already climbs Phase by Phase. Spending it in Week 1 leaves nothing to climb, and Foundation is for technique at Race load.
